# Yellow Zone Admin

لوحة الإدارة الحقيقية لـ Yellow Zone.

- Eman: إدارة كاملة.
- Alaa: الأسعار + الإعلانات والفعاليات.
- الإعلانات والحجوزات متصلة بـ Supabase.
- موقع العملاء يقرأ الإعلانات النشطة من نفس قاعدة البيانات.

ملاحظة: بيانات الدخول موجودة في `app.js` حسب طلب صاحب المشروع. هذا مناسب للاستخدام الداخلي المحدود، لكنه ليس نظام مصادقة قويًا لأن ملفات GitHub Pages عامة.


آخر التعديلات: زر واضح لإلغاء الحجز من صفحة الحجوزات، ومعاينة صور صغيرة للإعلانات والمعرض حتى لا تكبر الصفحة.
